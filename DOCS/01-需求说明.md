# 01 · 需求说明

## 项目定位
面向「完全不懂代码」的赛尔号新手，一个运行在 Windows 上的 PVE 关卡攻略查询工具。用户打关时点开即可查攻略。

## 目标用户
《赛尔号：巅峰之战》新手玩家，零编程基础。

## 核心功能
1. **关卡总览**：查询所有 PVE Boss 挑战关卡，按分类分组展示。
2. **搜索**：按关卡名 / 宠物名 / 分类名即时过滤。
3. **关卡详情**：每个关卡展示——
   - 新手首战推荐宠物（如星光鲁斯王）及其配招、养成
   - 通关所需宠物清单（以最优解为准）
   - 分步攻略 + 注意事项
4. **宠物详情**：点击宠物查看配招 / 养成 / 获取方式。
5. **新手时间线**：按「登录第 1 天 → 第 2 天 → … 最新」展示进度与该天可挑战的关卡。
6. **置顶**：把要打的关卡钉到最上方（本机持久化，刷新后仍在）。

## 已确认的关键决策
- **软件形态**：单文件网页版（`.html` 双击用浏览器打开，无需安装）。
- **数据来源**：Claude 上网查资料预填，用户可随时提出修正。
- **数据更新**：自动拉取 Claude 发布的在线 data.json，断网时用内置兜底数据。
- **首期范围**：先做框架 + 少量典型关卡，用起来后再逐步补全。

## UI 要求
- 简洁直观，主色调用「星光色」（深蓝夜空 + 银蓝/星点高光）。
- 卡片式布局、大字号、浅色文字；桌面为主，窄屏可单列自适应。

## 首期种子内容
- **宠物**：星光鲁斯王、王之哈莫（配招 + 养成）。
- **关卡**：谱尼七封印 / 谱尼真身、怒雷神裁·雷伊（四关）、灭战神决·盖亚（三关）、精灵王试炼、灵石守卫第三关。
- **时间线**：第 1 天、第 2 天（后续天数逐步补）。

## 非目标（暂不做）
- 不做 PVP 内容；不做实时抓取第三方攻略站；不做多端同步。
