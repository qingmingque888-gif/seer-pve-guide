# 02 · 技术设计规范

## 架构
单文件 HTML + 在线 JSON 自动拉取 + 内置兜底数据。

- 交付物：`赛尔号新手PVE攻略.html`（自包含 CSS / JS + 内置兜底数据）。
- 在线数据：`data.json` 托管在公开链接（GitHub raw / Pages，支持 CORS）。
- 打开时 JS 先 `fetch` 在线 data.json（带超时），成功用在线数据；失败回退内置兜底。
- 顶栏显示「数据更新时间」与来源（在线 / 离线兜底）。
- 置顶记录等本机偏好用 `localStorage` 存储。

## 数据流
1. 页面加载 → 尝试 fetch 在线 data.json → 校验结构 → 成功则渲染并标注「在线」。
2. fetch 失败/超时 → 使用 HTML 内嵌兜底数据 → 标注「离线兜底」。
3. 用户交互（搜索 / 置顶 / 展开 / 切换视图）全部在前端完成，无后端。

## UI 结构
- 顶栏：标题、更新时间/来源、搜索框。
- 标签页：`时间线` ｜ `全部关卡`。
- 时间线视图：左侧日期列表，右侧该天解锁关卡 + 当日必做。
- 全部关卡视图：按分类分组卡片，支持置顶（置顶项排最上）。
- 关卡详情：展开卡片显示推荐宠物 / 配招 / 养成 / 所需宠物 / 步骤。
- 宠物详情：弹窗显示配招 / 养成 / 获取。

## 代码规范
- 纯 HTML / CSS / JS，不引入框架、不依赖构建工具、不依赖外部库（保证离线可用）。
- 内嵌数据用 `const EMBEDDED_DATA = {...}` 放在独立 `<script>` 块，内容与 data.json 一致。
- 在线数据地址用常量 `DATA_URL` 集中定义，方便日后改托管位置。
- 渲染逻辑与数据分离：数据变更只改 data.json + 内嵌副本，不动渲染逻辑。

## 验证方式
1. **JSON 校验**：data.json 合法、字段完整、petId 引用正确。
2. **浏览器点验**：搜索 / 置顶（刷新仍在）/ 时间线切换 / 关卡详情 / 宠物详情。
3. **双路径**：联网能拉在线数据；断网或 fetch 失败回退内置并正常显示。
4. **零基础可用性**：双击即用，无需安装。

## 发布
- 建公开 GitHub 仓库托管 data.json + HTML（对外动作，先征得用户确认）。
- 游戏大版本更新后，更新 data.json 再推送，用户打开即自动更新。
